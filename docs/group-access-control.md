# 그룹 접근 권한 최소 구현 기준

기준일: 2026-11-06. 임시 세션 기반 단일 메모리 중계의 그룹 접근 통제다. 계정/차량 소유 인증·온라인 배포 승인 완료를 뜻하지 않는다.

## 역할과 수명

- 생성자가 그룹장이다. 서버가 세션 ID로 검사하며 요청 본문의 역할/차량 이름을 신뢰하지 않는다.
- 승인된 차량 최대 8대(그룹장 포함), 대기 요청 최대 10개/그룹, 요청 수명 5분. 한 세션은 한 그룹 또는 한 대기 요청만 가진다.
- 그룹장은 코드 재발급/폐기, 승인/거절, 자신 외 구성원 강제 퇴장을 할 수 있다. 다른 구성원의 관리 요청은403, 그룹 미참여자의 관리 요청은409로 거절한다.
- 그룹장이 탈퇴하거나 60초 무응답/2시간 세션 만료가 되면 그룹을 닫고 모든 위치·메시지·대기 요청을 지운다. 자동 양도는 없다. 참여자는 다음 응답/요청 실패 감지 때 공유를 중지한다.
- 일반 차량 탈퇴/퇴장은 해당 차량의 위치·공유 epoch와 작성 메시지/확인 기록을 제거한다. 강제 퇴장은 해당 세션의 그 그룹 재신청을 막는다. 새 세션은 사람을 식별하지 못하지만 여전히 그룹장 승인이 필요하다.

## 코드·승인

- 초대 코드는 40비트 난수, 발급 후30분. 코드는 그룹장에게만 제공하고 승인된 일반 차량에게도 숨긴다.
- 재발급은 새 코드를 발급하며 예전 코드와 모든 대기 요청을 즉시 폐기한다. 폐기는 새 코드 없이 초대를 닫고 대기 요청을 없앤다. 승인된 구성원은 유지한다.
- 코드를 입력하면 승인 대기가 된다. 승인 전에는 그룹 ID/코드/구성원/위치·목적지·ETA/메시지를 공개하지 않으며 업로드·공유 시작도 거절한다.
- 그룹장이 신청마다 새로 생성한 요청 ID를 보고 승인/거절한다. 이전 신청 ID로 새 신청을 승인할 수 없다. 승인 때도 요청5분 수명·정원·코드 유효성·그룹장 권한을 재검사한다. 같은 코드 중복 신청은 같은 요청으로 유지한다.
- 대기 취소는 ‘그룹 나가기’로 한다. 거절/만료/코드 변경/폐기/그룹 종료는 신청자에게 다음 폴링에 안내한다. 코드 만료는 승인된 구성원을 내보내지 않는다.
- 승인됐어도 위치 공유를 자동 시작하지 않는다. 각 차량이 기존 정차·권한·동의를 거쳐 공유를 시작한다.

## API와 앱

/v1 경로는 유지하되 승인 필수 계약으로 함께 업데이트한다. 구버전의 코드 즉시 참여는 지원하지 않는다. health apiVersion은2, 그룹 응답 accessVersion은2다. 앱은 accessVersion 불일치 시 실제 공유를 허용하지 않는다.

- POST /v1/groups/invite/rotate, /revoke
- POST /v1/groups/requests/approve, /reject: requestId
- POST /v1/groups/kick: memberId
- POST /v1/groups/join: code, 결과는 대기
- GET /v1/group: 본인의 승인/대기/퇴장 상태. 그룹장만 대기 목록과 유효 코드를 받는다.

앱 관리 UI는 실제 공유 화면 안에 두고 정차·연결·역할 조건으로 잠근다. 폐기·퇴장은 확인창과 실행 직전 정차 재검사를 한다. 주행 중 대기자 이름/관리 조작은 숨기며 공유 중지/탈퇴는 가능하다. 코드 복사는 유효 코드가 있는 그룹장만 가능하다. 화면은 서버 응답을 기준으로 갱신한다.

## 검증 기준

실제 HTTP로 미승인 정보 비노출/업로드 거절, 비그룹장/다른 그룹 권한 거부, 재발급·폐기 즉시 무효화, 승인·거절·요청 만료·정원·중복 처리, 퇴장 후 재신청 거부/이전 epoch 거부, 그룹장 종료, 서버 재시작을 확인한다. 기존 위치/ETA·메시지·정차 게이트 검사를 유지하고 네 빌드 변형을 검사한다. UI 런타임 검증 여부는 work-log에 구분한다.
